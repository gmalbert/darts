# 09 — Legal & Compliance

## Critical Warning

**You are not a licensed sportsbook. You are a content/analytics site that links to licensed sportsbooks.** The distinction matters legally. Everything on your site should be analysis and information — never "place this bet" — always "here's the model output, here's DraftKings' line."

Do not skip this section. Affiliate programs will terminate you, and platforms will delist you, for compliance failures.

## State-by-State Geo-Gating

DraftKings sportsbook is not available in all states. Your affiliate links should only be shown to users in legal states, or shown with appropriate caveats.

```ts
// lib/geo.ts
// Use Vercel's built-in geo headers (available on Edge runtime)
import { geolocation } from '@vercel/edge'

// States where DraftKings sportsbook is live (as of 2026 — verify regularly)
export const DK_LEGAL_STATES = new Set([
  'AZ', 'CO', 'CT', 'IL', 'IN', 'IA', 'KS', 'KY', 'LA',
  'MD', 'MA', 'MI', 'NJ', 'NY', 'NC', 'OH', 'OR', 'PA',
  'TN', 'VT', 'VA', 'WV', 'WY', 'DC',
])

// States where DraftKings Predictions (prediction market) is available
export const DK_PREDICTIONS_STATES = new Set([
  // 38 states — check draftkings.com/predictions for current list
  'CA', 'TX', 'FL', // and many others
])

export function getUserState(request: Request): string | null {
  const geo = geolocation(request)
  return geo.region ?? null  // e.g. 'MA', 'NY'
}

export function canShowDKSportsbook(state: string | null): boolean {
  return state ? DK_LEGAL_STATES.has(state) : false  // default false if unknown
}
```

```tsx
// middleware.ts — run on edge, add geo state to headers
import { NextResponse } from 'next/server'
import type { NextRequest } from 'next/server'
import { geolocation } from '@vercel/edge'

export function middleware(request: NextRequest) {
  const { region } = geolocation(request)
  const response = NextResponse.next()
  if (region) {
    response.headers.set('x-user-state', region)
  }
  return response
}
```

## DraftKings Affiliate Program

### How to Apply

1. Go to **draftkings.com/affiliates** or apply via **Impact.com** (DK's affiliate network)
2. You'll need: a live site (even basic), traffic estimates, marketing channels
3. Approval typically takes 1–3 weeks
4. Upon approval you receive tracking links and a pixel for conversion tracking

### Commission Structure (verify at sign-up — these change)

| Model | Rate | Notes |
|-------|------|-------|
| CPA (Cost Per Acquisition) | $200–$400 per depositor | Best when starting out |
| RevShare | 20–35% of net gaming revenue | Better long-term if retention is high |
| Hybrid | CPA + reduced RevShare | Available to high-volume affiliates |

### Link Implementation

```tsx
// Always use your affiliate tracking link, never raw DraftKings URLs
// Wrong:  href="https://sportsbook.draftkings.com/sports/darts"
// Right:  href="https://sportsbook.draftkings.com/sports/darts?wpcid=YOUR_AFFILIATE_ID"

// Or use Impact.com's generated links which include all tracking parameters

const DK_AFFILIATE_BASE = process.env.NEXT_PUBLIC_DK_AFFILIATE_URL
// e.g. https://record.draftkings.com/_SomeTrackingParams/

export function getDKEventUrl(eventPath: string = '/sports/darts'): string {
  // Impact.com generates the full URL — just append the path where possible
  return `${DK_AFFILIATE_BASE}${eventPath}`
}
```

### Things That Will Get You Terminated

- Bidding on "DraftKings" as a keyword in Google Ads (brand bidding is almost always prohibited)
- Using DraftKings branding/logos without approval
- Cookie stuffing or other fraudulent attribution methods
- Showing odds that don't match what DraftKings is actually offering
- Targeting users in states where DK is not licensed
