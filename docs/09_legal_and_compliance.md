# 09 — Legal & Compliance

## Critical Warning

**You are not a licensed sportsbook. You are a content/analytics site that links to licensed sportsbooks.** The distinction matters legally. Everything on your site should be analysis and information — never "place this bet" — always "here's the model output, here's DraftKings' line."

Do not skip this section. Affiliate programs will terminate you, and platforms will delist you, for compliance failures.

---

## Required Disclosures

### 1. Responsible Gambling — Every Picks Page

Add to every page that shows picks, odds, or betting analysis. Streamlit makes this easy with a `st.caption` or a styled `st.info` block:

```python
# components/disclaimers.py

def rg_banner(compact: bool = False):
    """Responsible gambling banner. Call on every picks/odds page."""
    import streamlit as st
    if compact:
        st.caption(
            "21+ only. Gambling problem? Call 1-800-GAMBLER (1-800-426-2537). "
            "Model outputs are for informational purposes only — not betting advice."
        )
    else:
        st.info(
            "**Responsible Gambling**  \n"
            "You must be 21 or older and located in a jurisdiction where sports betting is legal "
            "to wager on DraftKings. Model outputs on this site are for informational and "
            "entertainment purposes only and do not constitute betting advice. "
            "Past model performance does not guarantee future results.  \n\n"
            "If you or someone you know has a gambling problem, call the National Problem "
            "Gambling Helpline: **1-800-522-4700** (24/7) or visit "
            "[ncpgambling.org](https://www.ncpgambling.org).",
            icon="⚠️",
        )
```

### 2. Affiliate Disclosure — Every Page with Affiliate Links

## State-by-State Geo-Gating

DraftKings sportsbook is not available in all states. In Streamlit, you can read the visitor's region from request headers (if using a reverse proxy) or simply show a generic disclaimer. The simplest compliant approach:

```python
# Show affiliate links universally but with a jurisdiction disclaimer
import streamlit as st

DK_LEGAL_STATES = {
    "AZ", "CO", "CT", "IL", "IN", "IA", "KS", "KY", "LA",
    "MD", "MA", "MI", "NJ", "NY", "NC", "OH", "OR", "PA",
    "TN", "VT", "VA", "WV", "WY", "DC",
}

def dk_cta(path: str = "/sports/darts"):
    """DraftKings affiliate button with jurisdiction disclaimer."""
    import os
    tag  = os.getenv("DK_AFFILIATE_ID", "")
    url  = f"https://sportsbook.draftkings.com{path}"
    if tag:
        url += f"?wpcid={tag}"
    st.link_button("Bet at DraftKings", url)
    st.caption("Must be 21+ and located in a state where DraftKings is licensed.")
```

## DraftKings Affiliate Program

### How to Apply

1. Go to **draftkings.com/affiliates** or apply via **Impact.com** (DK's affiliate network)
2. You'll need: a live site (even basic), traffic estimates, marketing channels
3. Approval typically takes 1–3 weeks
4. Upon approval you receive tracking links and a pixel for conversion tracking

### Commission Structure (verify at sign-up — these change)

| Model | Rate | Notes |
|-------|------|-------|
| CPA (Cost Per Acquisition) | $200–$400 per depositor | Best when starting out |
| RevShare | 20–35% of net gaming revenue | Better long-term if retention is high |
| Hybrid | CPA + reduced RevShare | Available to high-volume affiliates |

### Link Implementation

```python
# lib/affiliates.py
import os

DK_AFFILIATE_ID = os.getenv("DK_AFFILIATE_ID", "")

def dk_url(path: str = "/sports/darts") -> str:
    """Always use your affiliate tracking link, never raw DraftKings URLs."""
    base = "https://sportsbook.draftkings.com"
    tag  = f"?wpcid={DK_AFFILIATE_ID}" if DK_AFFILIATE_ID else ""
    return f"{base}{path}{tag}"
```

### Things That Will Get You Terminated

- Bidding on "DraftKings" as a keyword in Google Ads (brand bidding is almost always prohibited)
- Using DraftKings branding/logos without approval
- Cookie stuffing or other fraudulent attribution methods
- Showing odds that don't match what DraftKings is actually offering
- Targeting users in states where DK is not licensed
