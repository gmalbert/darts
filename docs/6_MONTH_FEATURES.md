# BullzIQ — 6-Month Feature Roadmap

## Month 1: Event & Schedule Improvements

- **PDC calendar integration** — Pull full PDC schedule from API or scraper; display upcoming events with prestige tier badge (Major, Ranking, Floor).
- **Days to next major** — Hero banner countdown to the next World Darts Championship or Premier League event.
- **Tournament bracket viewer** — Visual bracket for elimination-format events.
- **Live score ticker** — Refresh current match scores every 60 seconds during live events.

## Month 2: Player Pages

- **Player profile** — Individual page: career stats, Elo trend chart, recent results, PDC ranking history.
- **Player comparison tool** — Side-by-side comparison of any two players: avg, checkout%, H2H record.
- **Career highlights** — Major titles, 9-dart finishes (from PDC records).

## Month 3: Predictions & Picks

- **Match prediction card** — Win probability + odds comparison for upcoming DraftKings-listed matches.
- **Format advantage flag** — Highlight when a player has a notable advantage in a specific format.
- **Best bets filter** — Show only matches with edge > 3%.

## Month 4: Analytics

- **H2H deep-dive** — Last 10 meetings: scoreline, format, tournament, winner.
- **Venue/crowd effect** — Players who outperform Elo at specific events (e.g., Alexandra Palace specialist).
- **Model accuracy tracker** — Rolling 20-match accuracy chart.

## Month 5: Community Features

- **Prediction leaderboard** — Track user picks vs. model picks (simulated, not real money).
- **Event recap** — Automated post-tournament summary: model accuracy, biggest upsets.
- **Share pick button** — Generate a shareable image card for any pick.

## Month 6: Automation

- **Event-week email** — Send PDC major preview with top picks each Wednesday before a major.
- **GitHub Actions pipeline** — Nightly fetch of new results and odds refresh.
- **Discord notification** — Post tournament draw and top picks to Discord webhook.
